# 实时同声传译（中→英 · 保留本音）调研报告

> 调研日期：2026-10-19 · 范围：云端 API（不做本地模型部署）· 目标：中文语音实时转英文语音，保留本人音色，价格与延迟最优。
> 结论会随厂商价格/接口变化；所有"官方宣称"与"实测"分开标注，签约前请复核 ToS。

---

## 0. 一页结论

1. **翻译这一步已经接近免费**：DeepSeek V4.1 Flash（`deepseek-flash`）非高峰输入 $0.15/百万 token、输出 $0.6/百万 token，1 小时会议翻译成本约 **$0.01**。把翻译交给通用大模型，是当前性价比最高的切法。
2. **更强的候选是 Omni 直达**：`qwen3.8-omni-flash-realtime` 单 WebSocket 完成识别+翻译+合成，配合 `qwen-voice-enrollment` 用 10–20 秒音频零样本复刻你的音色；音频按 25 token/秒计费，1 小时约 **¥1.69（$0.24）**，比级联再便宜约 3 倍。**已实测：句末→首音 766–859ms（p50 797ms），两句译文准确；声音复刻待用户录音。**
3. **成本大头不在翻译，在 ASR 与克隆 TTS**：全链路国产级联（百炼 `qwen3-asr-flash-realtime` + DeepSeek + 百炼 `cosyvoice-v3.5-flash`）约 **$0.7/小时（≈¥5）**；端到端 Palabra 约 **$2.4/h**、Azure 约 **$3.6/h**。级联比 Palabra/Azure 便宜，但比 Omni 直达贵约 3 倍。
4. **国内"单 API 真 S2S + 保留音色"**：阿里 `qwen3.8-omni-flash-realtime`（自带 Omni 声音复刻）、`qwen3.8-livetranslate-flash-realtime`（内置 0 样本实时复刻）、腾讯云实时语音翻译（单 WS + 一句话复刻）。讯飞同传是真 S2S 但只有 7 个预置发音人；火山豆包同传**只出文本不出音频**。
5. **国外真正端到端且能保留音色的**：Azure Live Interpreter + Personal Voice（需审批，$2.50/h）、Camb.ai Realtime（Beta，14 语言，`voice_id` 克隆）、Palabra（$0.04/分钟，零样本克隆）、ElevenLabs Realtime Translation（企业版限定）。Gemini Live Translate 与 OpenAI `gpt-realtime-translate` 目前**没有可用的音色参数**，不能按要求保留本音。
6. **网络比模型更决定成败**：所有国外厂商在中国大陆都没有本地 POP；跨境 RTT 与抖动会吃掉模型优势。国内用户建议"音频留境内"，只让文本走 DeepSeek（也在境内）。
7. **推荐架构**：首选 Omni 直达（单 API + 复刻音色，¥1.69/h）；级联作为兜底（¥5/h，可控/可字幕/可插术语）；端到端单 API 作对照。Phase 0 用同一组语料实测 3 条路线，选 1 主 + 1 备。

## 1. 需求与验收指标

| 指标 | 目标 | 说明 |
|---|---|---|
| 首音延迟（句末→英文首包） | 国内 p50 ≤1.5s / p95 ≤2.5s；跨境 p50 ≤2.5s | 单调时钟打点，导出 JSONL |
| 音色相似度 SECS | ≥0.72（及格）/ ≥0.80（良好） | CAM++/ECAPA 说话人嵌入 |
| 翻译 COMET | ≥0.80（领域测试集） | 参考译文对比 |
| 术语命中 | ≥95% | 20 条术语表 |
| 稳定性 | 60min 不中断；断流 10s 内恢复 | 双供应商 |
| 成本 | 国内 ≤¥30/h；海外 ≤$10/h | 以账单为准 |

"同声传译"定义为说话人不停顿、译音滚动输出；"音色"= 说话人身份特征；"语调"= 语速/音高/重音/情绪。

## 2. 三种架构范式

| 范式 | 含义 | 代表 | 优点 | 代价 |
|---|---|---|---|---|
| A. 真 S2S 单 API | 音频进、音频出，模型内部完成识别+翻译+合成 | 阿里 livetranslate、腾讯单 WS、讯飞同传、Camb、Azure、Palabra、ElevenLabs | 工程最少、延迟低 | 可控性弱、术语/文本难插、按分钟计费 |
| B. 单 WS 编排 | 对外一个接口，内部 ASR→MT→TTS | 腾讯实时语音翻译、讯飞同传 | 有文本、可挂克隆音色 | 仍是级联，参数隐晦 |
| C. 级联 + LLM 翻译 | ASR API + DeepSeek 翻译 + TTS API | 本方案默认 | 成本最低、可换件、可术语/上下文 | 三段延迟叠加、工程最多 |

关键认知：**"端到端"有三种不同含义**，营销口径容易混：
- 模型内部端到端，但只输出文本（火山豆包同传）——做英文语音仍要自己接 TTS；
- 单 API 真 S2S（阿里 livetranslate、Camb、Azure、Palabra）；
- 单 WS 编排（腾讯、讯飞）——对外一个接口，内部仍是 ASR+MT+TTS。

## 3. DeepSeek V4.1 作为翻译引擎（本次核心变化）

### 3.1 模型与价格（官方 2026-10 页面）

| 模型名 | 版本 | 上下文 | 最大输出 | 输入（缓存命中） | 输入（未命中） | 输出 |
|---|---|---|---:|---:|---:|---:|
| `deepseek-flash` | DeepSeek-V4.1-Flash-1017 | 1M | 384K | $0.003（非高峰）/ $0.006（高峰） | $0.15 / $0.30 | $0.6 / $1.2 |
| `deepseek-v4-pro` | DeepSeek-V4-Pro-0813 | 1M | 384K | $0.022 / $0.044 | $0.66 / $1.32 | $1.98 / $3.96 |

- 单位：USD / 百万 token。高峰时段为 UTC 周一至周五 01:00–04:00、06:00–10:00；其余时间与周末/中国法定假日为非高峰（半价）。
- `deepseek-flash` 并发上限 2500；支持 JSON、Tool Calls、Anthropic 格式。
- **思考模式默认开启**。实时翻译必须关闭，否则首 token 会被 CoT 拖慢：
  - OpenAI 格式：`{"thinking": {"type": "disabled"}}`，或 `reasoning_effort: "none"`。
- 流式：`stream: true`，SSE `data:` 帧，最后 `[DONE]`。

### 3.2 翻译成本估算

按 1 小时会议、每分钟 250 输入 token + 250 输出 token（约 15k/15k）：

| 场景 | 成本 |
|---|---:|
| 非高峰、无缓存 | 15k×0.15/1M + 15k×0.6/1M ≈ **$0.011** |
| 高峰 | ≈ **$0.022** |
| 每天 8 小时、每月 22 天、高峰 | ≈ **$3.9/月** |

结论：**翻译成本可以忽略**。真正决定总价的是 ASR 与 TTS 的按小时/按字符计费。

### 3.3 Prompt 与流式策略

- 系统提示：只输出译文，不加解释/引号/原文；保留数字、人名、术语；片段不完整时译完整部分。
- 术语表：`术语 => 译名` 逐条注入 system；每次请求带最近 2–4 句上下文。
- 稳定前缀：只翻译"已稳定 ≥2 帧"的 ASR 前缀 + 2–3 词 lookahead，避免译文抖动。
- 不要把每个 partial 都翻译；那会让字幕/语音反复重排。

| 限流 | **RPM 10 / TPM 100,000**，实时同传必须提额 |
| 其他 | 3.8 ASR 强制开启且免费；上下文 53248；音色绑定 `target_model` 不可跨模型 |
| 风险 | 官方未给端到端延迟；RPM 10 是硬约束；音频按 token 计费需实测 |

### 4.2 腾讯云实时语音翻译

| 项 | 事实 |
|---|---|
| 形态 | **单 WS 编排** ASR+MT+TTS；`wss://asr.cloud.tencent.com/asr/speech_translate/<appid>?...` |
| 音色 | 一句话复刻场景：`voice_type` 固定填 `"200000000"`，真正的复刻音色 ID 放 `fast_voice_type` |
| 限制 | `enable_tts` 仅 target=`zh`/`en`/`zh_en`；单会话合成 ≤10000 字；16k/mono，200ms/6400B；间隔 >6s 断连 |

### 4.3 讯飞同声传译

- 单 WS 真 S2S：`ws(s)://ws-api.xf-yun.com/v1/private/simult_interpretation`，同流返回原文/译文/TTS 三路。
- 16k/16bit/mono、40ms/1280B；`vto`/`eos` 可调 VAD。
- **只有 7 个预置发音人，不能保音色**。若必须保音色，改用"同传/ASR+MT"+"一句话复刻多风格版（8 语种）"两段拼。

### 4.4 火山引擎（重要更正）

- 豆包同声传译 API 真实存在（`wss://ark-beta.cn-beijing.volces.com/api/v3/realtime?service=clasi&model=<Model>`），但 `session.modalities` 文档原文："输出内容的模态，目前只支持 text"。
- 下行只有 `response.input_audio_transcription.delta`（原文）与 `response.input_audio_translation.delta`（译文）。
- 因此它是 **A 类：模型内部端到端但只出文本**，不是 S2S。要做英文语音必须再接豆包 TTS + 声音复刻。
- 声音复刻 2.0 需单独开通；预付费音色每个最多训练 15 次，"启用"后不可重训；后付费音色首次合成即收费并固化。

### 4.5 其他

- 智谱 GLM-Realtime：对话模型，翻译靠 instructions，仅 7 个预置音色、无复刻；0.18 元/分钟（≈¥10.8/h），不适合做同传底座。
- MiniMax：TTS + 快速复刻，但**无实时 S2S 翻译接口**，需自拼 ASR+MT。
- 百度智能云、商汤日日新：文档站 SPA，本次未取到正文，未核实。

### 4.6 百炼实时 ASR/TTS 与托管开源模型（二次核实）

- **百炼 `qwen3-asr-flash-realtime`**：WebSocket 真流式，11 语种，$0.000047/秒（北京）≈ **$0.169/小时**，RPM 1200。这是国内可落地的实时 ASR 首选。
- **百炼 `cosyvoice-v3.5-flash` / `cosyvoice-v3-flash`**：5–20 秒参考音零样本克隆 + 真 WebSocket 流式；`v3.5-flash` $0.116/万字符，`v3-flash` $0.14335/万字符；克隆音色绑定 `target_model`，另有 9.9 元/音色解锁费。
- **SiliconFlow `FunAudioLLM/CosyVoice2-0.5B`**：¥0.05/千 UTF-8 字节，`stream:true`，`references` 零样本克隆，境内直连；中文 1 万字符≈30KB≈¥1.5。
- **DeepInfra `Qwen/Qwen3-TTS`**：Apache-2.0 权重、3 秒克隆、PCM 流式、厂商标称 ~97ms 首字节、$20/百万字符；跨境延迟需实测。
- **开源 CosyVoice3 没有托管 endpoint**：HF 上无任何 Inference Provider 映射，SiliconFlow 只到 CosyVoice2，fal/Replicate 搜不到 cosyvoice3。**不要把"托管 CosyVoice3"写进排期。**
- Seed-VC 零托管；GPT-SoVITS 只有训练托管，没有推理 endpoint；IndexTTS-2 在 Replicate/fal 有托管，但 bilibili 协议对超大规模有单独授权要求。
- 许可证不因"托管"而消失：F5-TTS（CC-BY-NC-4.0）、Fish Speech（CC-BY-NC-SA-4.0）仍不可商用；Seed-VC 是 GPL-3.0。全链路优先 Apache-2.0/MIT（Qwen3-ASR、CosyVoice2/3、Qwen3-TTS、Chatterbox、Kokoro）。

### 4.7 Qwen3.8-Omni 直达：单 API S2S + 声音复刻（新增，首选验证）

| 项 | 事实 |
|---|---|
| 模型 | `qwen3.8-omni-flash-realtime`；输入文本/流式音频/视频，输出文本+音频；36 种语音生成语言；默认音色 Tina |
| 接入 | WebSocket / WebRTC / AOQ；WebSocket 必须用绑定业务空间的地址 `wss://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api-ws/v1/realtime?model=...`；请求头 `Authorization: Bearer <Key>` |
| 会话配置 | `session.update`：`modalities:["text","audio"]`、`instructions`、`turn_detection`、`audio.input.format`（16k PCM s16le）、`audio.output.voice` + 24k PCM 格式 |
| 音频流 | `input_audio_buffer.append`（base64 PCM16，3200 字节≈100ms）→ `input_audio_buffer.commit` → `response.create`；返回 `response.audio.delta`（base64 PCM16 24k）、`response.audio_transcript.delta`、`response.text.delta`、`response.done` |
| 音色复刻 | `qwen-voice-enrollment`，10–20 秒干净音频（≥24k、单声道、≤60s、<10MB），`target_model=qwen3.8-omni-flash-realtime`；返回 `qwen-omni-vc-...`，填到 `session.audio.output.voice`；**无需训练** |
| 复刻价格 | ¥0.01/音色；开通后 90 天内 1000 次免费；单个音色一年未使用会自动删除 |
| 模型价格 | 北京：音频入 ¥6/M token、音频出 ¥12/M token、文本/图片/视频入 ¥1.5/M、文本出 ¥4.5/M；免费额度 100 万 token（90 天） |
| Token 换算 | **每秒音频 = 25 token**；1h 音频 ≈90k token |
| 成本估算 | 入 ¥0.54 + 出 ¥1.08 + 文本出约 ¥0.07 ≈ **¥1.69/h（$0.24）**；复刻一次性 ¥0.01 |
| 优势 | 单 API、延迟链路最短、自带音色复刻、成本最低；有文本 transcript 可做字幕 |
| 风险 | 通用对话模型，必须用 instructions 强约束"只翻译"；可能加话/抢话；翻译质量、首音、VAD 手感均待实测；账户需无欠费且模型已开通 |

**实测（2026-10-19）**：账户恢复后，`qwen3.8-omni-flash-realtime` 已可调用。2 句中文→英文，句末→首音 **766–859ms（5 次，p50 797ms）**，译文准确（三百万/下周一均正确），输出 24kHz 单声道。**声音复刻已实测**：15s 样本创建成功，克隆音色首音 **937–968ms**（Tina 766–859ms），SECS 待计算；A/B 见 `results/voice_ab.wav`。通用 WebSocket 地址可通，生产建议用 Workspace ID 域名。详见 `docs/omni-measurements-2026-10-19.md`。

## 6. 推荐架构

### 6.1 首选（待实测）：Qwen3.8-Omni 直达

```
麦克风 48k → 16k PCM16 → qwen3.8-omni-flash-realtime（单 WebSocket）
  → 英文语音 + 复刻音色（qwen-omni-vc-...）→ playout buffer 150–300ms
  → VB-Cable 虚拟麦 / 耳机 + 英文字幕
```

理由：单 API 完成识别+翻译+合成，链路最短；自带 10–20s 零样本声音复刻；1h ≈ **¥1.69**，是当前最便宜的可落地方案。
代价：通用对话模型需强 instructions 约束；翻译质量/首音/VAD 待实测；账户需开通。

### 6.2 兜底：云端级联（可控）

```
麦克风 48k → resample 24k/16k PCM16
  → 区域流式 ASR（阿里/腾讯/讯飞）        [音频留境内]
  → 稳定前缀 + 术语表/上下文
  → DeepSeek V4.1 Flash（stream，thinking disabled）  [文本，成本≈0]
  → 克隆 TTS（阿里 CosyVoice / 腾讯 / 火山 / ElevenLabs）
  → playout buffer 200–400ms
  → VB-Cable 虚拟麦 / 耳机 + 双语字幕
```

理由：
- 翻译成本≈0，质量/术语/上下文可控；
- ASR/TTS 音频留境内，合规与延迟双赢；
- 每段可替换、可观测；避免被单一端到端厂商锁死。
代价：三段编排、三段延迟叠加，1h ≈ **¥5**。

### 6.3 对照：其他端到端单 API

- 国内：阿里 livetranslate（0 样本克隆）或腾讯单 WS（一句话复刻）。
- 海外：Palabra（$0.04/min，<1s）或 Azure（$2.5/h，需审批）；Camb 作为克隆音色备选。
- 用途：极低延迟模式、跨境用户、或前两条路线故障时的降级。

### 6.4 关键工程约束

- **传输**：直接使用厂商 WSS/SDK；不自建 WebRTC/SFU，不引入 LiveKit Agents 的"轮次对话"语义（同传是连续流）。
- **播放缓冲**：网络抖动缓冲与 TTS chunk 到达抖动分开处理；宁可加 100ms，不要断音。
- **反馈环路**：译音只进虚拟声卡，不同时进扬声器；否则会议软件拾音会啸叫。
- **虚拟声卡**：用 VB-Cable，不自研驱动（Windows 驱动需 EV 签名 + WHQL）。
- **断流**：双供应商 + 10s 内重连；ASR 切换保留 1.5s 音频 ring buffer 断点重传。

## 7. 延迟预算（工程估算）

| 段 | 国内典型 | 跨境典型 |
|---|---:|---:|
| 采集/重采样/打包 | 30ms | 30ms |
| 上行网络 | 10–20ms | 30–80ms（港/新）/ 130–200ms（美西） |
| ASR 首个稳定 partial | 200–500ms | 200–500ms |
| DeepSeek 首 token（thinking 关闭） | 200–400ms | 200–400ms |
| TTS 首包 | 150–300ms | 150–300ms |
| 下行 + playout | 150–300ms | 200–400ms |
| **合计** | **0.8–1.5s** | **1.3–3.0s** |

人类同传的"听译间距"是 2–4 秒，所以 1 秒不是瓶颈；真正的体验问题是**译文抖动**与**术语一致性**。

## 10. Phase 0 供应商 bake-off

同一组 30 句中文、同一说话人、同一网络，测 9 套：

1. 阿里 livetranslate（`once` 克隆）
2. 腾讯实时语音翻译（`fast_voice_type` 克隆）
3. 讯飞同传（无克隆基线）
4. Camb Realtime（`voice_id` 克隆，Beta）
5. Azure Live Interpreter + Personal Voice
6. Palabra（$0.04/min）
7. 全链路国产级联：百炼 `qwen3-asr-flash-realtime` + DeepSeek `deepseek-flash` + 百炼 `cosyvoice-v3.5-flash`（零样本克隆）
8. 备选 TTS：SiliconFlow CosyVoice2（更便宜，验证音质是否够用）
9. 百炼 Qwen3.8-Omni 直达 + 声音复刻（单 API S2S，¥1.69/h）

指标：首音 p50/p95、SECS、COMET、术语命中、¥/h、30min 稳定性、开通难度。
决策门槛：首音 p50 ≤2s（国内 ≤1.5s）、SECS ≥0.72、COMET 不低最优 0.05、成本 ≤预算、30min 无致命断流。

## 14. App 交付（2026-10-19）

- **Windows 桌面版**：`dist/RTI/RTI.exe`（PyInstaller，窗口模式），拆成 **同传页** + **独立音色制作页**（`studio.html`）；`config.json` 默认 `pro_voice` 为 **CosyVoice 3.5 专业复刻**，同传页填 Key 即可用；音色制作页录音后同时创建 Omni 兜底和 CosyVoice 专业音色。
- **免安装包**：`dist/RTI-windows.zip`（约 37MB），解压运行 `RTI.exe`。
- **Android 独立版**：`dist/RTI-android.apk`（原生 Java，AudioRecord/AudioTrack + Java-WebSocket），拆成 **MainActivity 同传屏** + **VoiceStudioActivity 音色制作屏**；Omni 只出译文文本，CosyVoice 3.5 流式 TTS 出声；Android 8+ 侧载。
- **翻译策略**：Omni `server_vad` 只切句（`create_response:false`），网关在 `speech_stopped` 后主动 `response.create`，并在 `response.instructions` 中强制“翻译引擎，不是助手；问题/命令只翻译不执行”。实测“今天天气怎么样 / 请写诗 / 解释量子力学”均只输出英文翻译，不再对答。
- **专业音色**：CosyVoice 3.5-plus 复刻，干净 15 秒样本（`voice.wav`）+ 音量归一化；返回 `cosyvoice-v3.5-plus-provoice2-...`，同传默认使用；合成 PCM 24k 字节 245KB/5s 左右，峰值约 0.6。
- **双向对谈（桌面）**：`web/duo.html`，两个独立 `/ws`（`profile=self/peer`）、两个输入设备、两套专业音色；对方英文→中文（`peer_pro_voice`，中文 TTS），我中文→英文（`pro_voice`，英文 TTS）。开启 `collect=true` 后按 speech_stopped 保存语音段，累计约 30 秒后台自动重做 CosyVoice 3.5 专业音色并更新当前会话后续 TTS。
